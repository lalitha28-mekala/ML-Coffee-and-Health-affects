# ☕ Coffee Intake & Health Condition Prediction

## 🔗 Live Demo

**Try the application:** [Coffee Health Prediction App](https://huggingface.co/spaces/Lalithamekala/ML_coffee_Health_affect)

## 📌 Project Overview

This project explores coffee consumption, lifestyle habits, and health-status categories using data analysis and machine learning.

The application provides an interactive interface to explore data patterns and generate model-based predictions using the available input features.

## 🎯 Objectives

- Explore coffee consumption and lifestyle-related data.
- Perform Exploratory Data Analysis (EDA) to identify patterns and trends.
- Prepare data for machine learning.
- Develop and evaluate a classification model.
- Build an interactive application using Streamlit.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Class Imbalance Handling:** Imbalanced-learn and SMOTE
- **Web Application:** Streamlit

## 📊 Project Workflow

1. **Data Inspection:** Examine the dataset structure, columns, and data types.
2. **Data Preprocessing:** Prepare the data for analysis and model training.
3. **Exploratory Data Analysis:** Visualize distributions, class frequencies, and relationships between selected features.
4. **Model Development:** Train a classification model using the prepared data.
5. **Model Evaluation:** Assess performance using appropriate classification metrics.
6. **Application Development:** Use Streamlit to provide an interactive interface for exploring data and generating predictions.

## 💡 Key Features

- Interactive Streamlit application.
- Dataset exploration and visualizations.
- Coffee intake and lifestyle feature analysis.
- Machine-learning-based health-status classification.
- Prediction interface for entering feature values.

## 🚀 Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/lalitha28-mekala/Coffee-Health-Risk-Prediction.git
cd Coffee-Health-Risk-Prediction
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.
